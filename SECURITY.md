## Secret hygiene

- Never commit API keys, tokens, private keys, or `.env` files to any repository in **AI-Architect-Studio**.
- All repositories enforce secret scanning before merge.

## Reporting a vulnerability

Please report suspected vulnerabilities privately via GitHub Security Advisories on the affected repository (`https://github.com/AI-Architect-Studio/<repo>/security/advisories/new`) rather than opening a public issue.
